# 🌐 Portfolio Website

My personal portfolio website built to showcase my skills, projects, education, and certifications in a clean and modern UI.

## Problem Statement

Students and developers need a professional online presence to highlight their skills, academic achievements, and projects in one place.

## Solution

This project is a responsive portfolio website developed using HTML, CSS, and JavaScript.
It provides a structured and visually appealing way to present personal and professional information.

## Features

* Fully responsive design (mobile + desktop)
* Smooth scrolling navigation
* Modern UI using Tailwind CSS
* Interactive project cards with hover effects
* Certification preview modal (click to view certificates)
* Back-to-top button
* Social media & contact integration

## 🛠️ Technologies Used
* HTML
* CSS
* JavaScript
* Tailwind CSS
* jQuery
* Lucide Icons

## 📂 Sections

* 🏠 Home (Introduction + Profile)
* 👤 About (Brief description)
* 🎓 Education (Academic details)
* 💻 Skills (Programming + Tools)
* 📁 Projects (Featured work)
* 📜 Certifications (with preview modal)
* 📬 Contact (Email + LinkedIn + GitHub)

## Projects Included

* 🚗 Smart RC Vehicle for Plant Disease Detection
* 🧊 Smart Refrigerator Inventory System
* 📚 EduPath JEE
